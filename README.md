# Gut-Health-Coach
Gut Health Coach is an empathetic, science-backed conversational assistant designed to answer gut-related health queries with clarity, kindness, and accuracy. It uses a lightweight RAG (Retrieval-Augmented Generation) pipeline built with LangChain, Zephyr-7B, and FAISS.
# Features
-Retrieval-Augmented Generation with FAISS and HuggingFace embeddings
-Powered by Zephyr-7B for aligned and safe responses
-Friendly, supportive tone inspired by coaching tools like August AI
-Context-aware answers from scraped, trusted medical sources (e.g., Mayo Clinic, Healthline)
-Tested against 10+ critical gut health queries
